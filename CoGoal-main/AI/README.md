# Контекст CoGoal-main для новых чатов

Эта директория помогает восстановить границы main и принятые решения без истории переписки. Она описывает реализованное поведение и план дальнейшей работы; запланированный API не следует считать готовым кодом.

| Файл | Когда читать |
| --- | --- |
| [design/main-service.md](design/main-service.md) | Изменения main: ответственность сервиса, данные, пакеты, JWT и Kafka |
| [design/main-roadmap.md](design/main-roadmap.md) | Новые функции: разделы контракта, зависимости и вопросы к бизнес-правилам |
| [skills/cogoal-main/SKILL.md](skills/cogoal-main/SKILL.md) | Инструкции агенту, который реализует или меняет main |
| [skills/plain-writing/SKILL.md](skills/plain-writing/SKILL.md) | Общие правила краткого и понятного текста для дизайна и документации |

Основной контракт — [OpenAPI](../../docs/api/openapi.yaml). [README backend](../../README.md) содержит команды запуска, тестов и локальные адреса. Внешние требования находятся в [репозитории документации CoGoal](https://github.com/CoGoal/project-documentation); в части UUID они устарели: в текущем проекте согласован BIGINT.

Для нового чата достаточно попросить: «Работай с CoGoal-main; начни с его AGENTS.md и AI/README.md, затем реализуй указанный раздел OpenAPI». Скилл лежит внутри этой директории по выбранному расположению; это само по себе не гарантирует автоматического обнаружения каждым инструментом. Его можно передать явной ссылкой. AGENTS.md служит короткой точкой входа для инструментов, которые читают этот файл.

После реализации функции обнови её статус в design и контракт, если изменилось внешнее поведение. Бизнес-правила держи в OpenAPI и целевых требованиях; здесь фиксируй решения о владении данными и реализации, не копируя весь контракт.
